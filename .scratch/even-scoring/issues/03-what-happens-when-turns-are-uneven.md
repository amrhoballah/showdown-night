# What happens when turns are uneven at game end?

Type: grilling
Status: resolved
Blocked by:

## Question

In turn-based games, ending when team A has had 3 turns and team B 2 inflates A's game score. Ignore it, warn, or normalise (e.g. rank by points per turn)?

## Answer

**Warn, but allow.** Ending a game with uneven turns shows a warning; the host can still confirm and end it. No normalisation. Which games count turns and what exactly triggers the warning is open: see "Which games count turns, and what triggers the uneven-turns warning?".
