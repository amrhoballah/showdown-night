# Are all games worth the same?

Type: grilling
Status: resolved
Blocked by:

## Question

A 40-minute Jeopardy board and a 5-minute Emoji run would award the same maximum placement points. Equal weight, a fixed weight per game type, or a weight the host picks at game start?

## Answer

A **fixed weight per game type**, held in a config that can be tuned later (not chosen by the host at game start). Initial values are open: see "What are the starting weights per game type?".
