# Does the night survive a page reload?

Type: grilling
Status: resolved
Blocked by:

## Question

Today every score is lost if the tab reloads. Is persisting scores part of this effort?

## Answer

**Yes.** Game scores (and what depends on them) are persisted in browser web storage (localStorage or sessionStorage). Which one, and exactly what is saved, is open: see "What does a saved night contain, and where is it stored?".
