# How does the host correct a wrong score?

Type: grilling
Status: resolved
Blocked by:

## Question

When a score was added wrongly, what does the host correct, and how: type a corrected value, or undo individual awards from a history?

## Answer

The host **sets a game score directly** (e.g. Team A → 1,200); no per-award history or undo. Game scores are the single source of truth: they stay editable **after a game has ended**, and the night standings are recalculated from them. The standings themselves are never edited by hand. The editing surface is open: see "Where and how does the host edit a game score?".
